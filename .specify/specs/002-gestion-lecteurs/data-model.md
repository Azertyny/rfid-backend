# Data model: Gestion des lecteurs (002)

## Reader (`reader` table, `entity/ReaderEntity.java`)

| Field | Type | Constraints | Change |
|---|---|---|---|
| `id` | UUID | PK, generated | unchanged; **now exposed** in the API `Reader` schema (research R1) |
| `name` | string | not null, unique (case-sensitive in DB) | unchanged column. The API calls it `uid`. It is stored trimmed. New creations are 1–50 characters and unique ignoring case (FR-001a, FR-007; checked in `ReaderService`) |
| `apitoken` | string(64) | not null, unique | unchanged; can now be **replaced** by a rotation (FR-006). Generated by `ReaderEntity.newApitoken()` (research R6) |
| `active` | boolean | not null, DB default `true` | **new** (FR-006). `@ColumnDefault("true")` + `@Builder.Default = true` (research R4) |
| `creationDate` | timestamp | not null, not updatable | unchanged |
| `updateDate` | timestamp | not null, `@UpdateTimestamp` | unchanged; also changes on rotation and on activation changes |

Not in this feature: the `mode` field (`PRODUCTION` / `ENREGISTREMENT`) belongs to spec `003`. `UpdateReader` is shaped so that `mode` can be added later (research R2).

### Relationships

- `Record.reader` → `Reader` (`RecordEntity.java`, `reader_id` not null). This link is why readers are never deleted (FR-006): deactivating a reader keeps its records.

### Repository

- `ReaderRepository.existsByNameIgnoreCase(String name)`: **new**, for FR-007.
- `findByApitoken`: unchanged. The scan filter uses it, and it now also checks `active`.

## Validation rules

| Rule | Where | Response |
|---|---|---|
| `uid` present | `api.yaml` `required` (generated `@NotNull`) | `400` |
| `uid` ≤ 50 characters (before trimming) | `api.yaml` `maxLength` (generated `@Size`) | `400` |
| `uid` not blank after trimming | `ReaderService` | `400` |
| no existing reader with the same trimmed `uid`, ignoring case | `ReaderService` + `existsByNameIgnoreCase` | `409` |
| same-case race caught by the DB unique constraint | `ReaderService` (`saveAndFlush`, `DataIntegrityViolationException` → `ReaderAlreadyExistsException`) | `409` |
| `UpdateReader` has at least one field | `ReaderService` | `400` |
| `readerId` exists | `ReaderService` → `ReaderNotFoundException` | `404` |

## State: active / disabled

```text
          create
            │
            ▼
   ┌──── ACTIVE ◄──────────────┐
   │   (token accepted          │ PATCH {active:true}
   │    on /tags/scan)          │ (current token works again)
   │                            │
   │ PATCH {active:false}       │
   ▼                            │
DISABLED ──────────────────────┘
(token → 401 on /tags/scan; still listed in GET /readers; records kept)

Token rotation (POST /readers/{id}/token): allowed in both states, state unchanged,
old token → 401 from the next request on.
```

Setting a reader to the state it already has is a no-op that still answers `200`.
